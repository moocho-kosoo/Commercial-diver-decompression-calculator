다이빙 계산기 사용설명서

US Navy Diving Manual Rev. 7 기준 감압 계산기 3종을 한 페이지에 모았습니다. 상단 탭을 눌러 계산기를 전환할 수 있으며, 탭을 오가도 입력값은 유지됩니다.

1. 산업잠수 감압계산기

  • 산업(상업) 잠수용 감압 계획 계산기입니다.
  • Air / HeO₂ 두 가지 호흡기체 모드를 지원합니다.
  • 수심과 해저체류시간을 입력하면 Table 9-9(공기) 또는 Table 12-4(혼합기체) 기준으로 감압 정지 일정을 계산합니다.
  • 수중 산소 감압, 산소 표면감압(SurDO₂) 절차를 지원합니다.
  • 뉴모(pneumofathometer) 수심 보정이 자동 적용됩니다.

2. 레저다이빙 감압계산기

  • 레저 다이빙용 무감압 한계 계산기입니다. 감압 정지 일정은 만들지 않습니다.
  • Table 9-7(무감압 한계·압력그룹), Table 9-8(잔류질소시간) 기준입니다.
  • 단일 다이빙과 3차까지 반복다이빙을 지원합니다.
  • 수심 입력 시 무감압 한계시간, 시간 입력 시 최대 수심을 빨간 글씨로 실시간 안내합니다.
  • 매 다이빙 후 5m(15ft) 3분 안전정지를 안내합니다.

3. 잠수기록도표 계산기

  • 잠수기능사 필기시험의 잠수기록도표를 자동으로 작성해주는 계산기입니다.
  • 아래 5개 항목만 입력하면 도표 전체가 자동 기입됩니다.
  • 감압 절차에서 수중 감압 또는 챔버 감압을 선택할 수 있습니다. 챔버 감압은 Table 9-9의 SurDO₂ period에 따라 챔버 해저도착, 50/40/30/20ft 감압란, 챔버 해면도착을 계산합니다.

4. 환기·지연 규칙 요약 (US Navy Rev. 7)

환기 (Ventilation)

  • 수중 30/20fsw에서 산소로 전환할 때 20초 환기를 실시합니다 (9-8.2.1).
  • Travel/Shift/Vent 시간은 3분 이내를 권장합니다.
  • 산소 30분마다 5분 Air Break을 실시하며, 이 시간은 dead time입니다.
  • SurDO₂ 챔버 50ft 도착 후에는 별도 환기 없이 바로 산소 마스크를 착용합니다 (9-8.3.1).

지연 (Delay)

  • 해저체류시간은 수면을 떠난 시점부터 기산되므로, 하강 중 지연은 자동으로 포함됩니다 (9-3.2).
  • 첫 정지점 도착 지연 1분 이하: 무시 (9-11.3).
  • 첫 정지점 도착 지연 1분 초과, 50fsw보다 깊은 경우: 지연시간을 올림하여 해저체류시간에 가산 후 감압표를 다시 조회합니다.
  • 첫 정지점 도착 지연 1분 초과, 50fsw보다 얕은 경우: 지연시간을 첫 정지시간에 가산합니다.
  • 정지 이탈·정지 사이 지연 1분 미만: 무시 (9-11.4).
  • 수중 40ft → 챔버 50ft 이동은 5분 이내여야 합니다 (SurDO₂).

5. 계산 결과 인쇄 방법

  1. 원하는 계산기 탭에서 값을 입력한 뒤 계산을 실행하여 결과를 화면에 표시합니다.
  2. Android는 브라우저 오른쪽 위의 더보기(⋮)에서 공유 → 인쇄를 선택합니다. 브라우저에 따라 더보기 메뉴에 인쇄가 바로 표시될 수 있습니다.
  3. iPhone·iPad는 브라우저의 공유 버튼을 누르고 메뉴를 아래로 내려 프린트를 선택합니다.
  4. 용지는 A4, 방향은 세로로 설정하고, 미리보기에서 현재 계산 결과가 끝까지 표시되는지 확인한 뒤 인쇄합니다.
  5. 종이 대신 파일로 보관하려면 인쇄 화면에서 PDF로 저장을 선택합니다.

기기와 브라우저에 따라 인쇄 범위가 달라질 수 있으므로, 미리보기에서 상단 탭이나 입력 화면이 아닌 현재 계산 결과 전체가 선택되었는지 반드시 확인하십시오.
